## ✅ 使用方法

### 步骤1：在 Label Studio 中更新配置

1. 打开你的 Label Studio 项目
2. 进入 **Settings** → **Labeling Interface**
3. 删除旧的 XML 配置
4. 复制 `labeling_config_fixed.xml` 的内容
5. 粘贴到编辑器中
6. 点击 **Save** 保存

### 步骤2：验证修复效果

1. 进入标注界面
2. 选择一张"环境实拍图"
